A long-running time-management franchise. The core gameplay and mechanics were already in place, so the job wasn't to invent a game but to make a new installment within the series' strict constraints.

\{Steam|https://store.steampowered.com/app/4895990/Argonauts_Agency_The_World_on_His_Shoulders/\}

## Objectives

* Help shape the project's vision: define the locations and the main storyline
* Create 60 levels

## My contribution

* Contributed to shaping the project's vision: the locations and the main storyline
* Designed and tested the levels (60)
* Added a new game object to an existing mechanic
* Integrated assets and set up game objects in the engine
* Handled localization: in-game text and AI-assisted translation

## Outcome

* Premium release on Steam
* Free-to-play release on mobile
* Positive player reception

## What I'd do differently

* Make the onboarding in levels 1–10 smoother
